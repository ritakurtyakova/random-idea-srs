# Диаграммы поведения системы

## Use Case Диаграмма

Диаграмма описывает основные сценарии взаимодействия пользователя с приложением «Генератор случайных идей».

### Акторы:
- **Пользователь** — основной пользователь системы, который генерирует идеи, сохраняет понравившиеся идеи и экспортирует избранное.

### Основные Use Cases:
- Генерация случайной идеи
- Настройка параметров генерации
- Сохранение идеи в избранное
- Просмотр истории генераций
- Копирование идеи
- Удаление идеи из избранного
- Очистка истории
- Экспорт избранного в TXT

## Диаграммы последовательности

### 1. Генерация случайной идеи
Показывает процесс получения случайной идеи и её отображения в интерфейсе приложения.

### 2. Добавление идеи в избранное
Демонстрирует сохранение понравившейся идеи в избранное с использованием localStorage.

### 3. Экспорт избранного
Отображает процесс получения списка избранных идей и формирования TXT-файла для скачивания.

## Используемые инструменты
- **PlantUML** — для создания диаграмм с помощью кода.
